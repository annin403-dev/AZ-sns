# モールドール マルシェ紹介動画 🐻

Instagram Short サイズ (1080×1920, 9:16) の商品紹介動画です。

## セットアップ

```bash
cd remotion
npm install
```

## 画像ファイルの配置

`public/images/` フォルダに以下のファイルを入れてください：

| ファイル名 | 内容 |
|---|---|
| `dolls-shelf.jpg` | 棚に並んだドールの写真（送ってもらった1枚目）|
| `wreath-group.jpg` | リースに複数のドールが入っている写真（2枚目）|
| `wreath-rainbow.jpg` | レインボーカラーのドール×リース（3枚目）|
| `wreath-white.jpg` | 白いドール×リース（4〜5枚目どちらか）|
| `bgm.mp3` | BGM音楽ファイル |

## BGM音楽について

ポップでかわいいロイヤリティフリー音楽を推奨します：

- **Pixabay Music**: https://pixabay.com/music/
  検索ワード: `cute pop`, `kawaii`, `happy ukulele`, `uplifting`
- **Bensound**: https://www.bensound.com/
  おすすめ: `Ukulele`, `Sunny`, `Happy`
- **Freepd**: https://freepd.com/
  おすすめ: Childrenカテゴリ

## 動画の構成（25秒）

| 時間 | シーン | 字幕ナレーション |
|---|---|---|
| 0〜5秒 | オープニング | こんにちは！私が作ったモールドールを紹介します🐻 |
| 5〜12秒 | ドール棚紹介 | ピカチュウ・キティちゃん・BT21…全部、私が手で作りました！ |
| 12〜20秒 | リースアレンジ | フラワーリースと合わせても可愛いでしょ？ひとつひとつ丁寧に作っています💕 |
| 20〜25秒 | マルシェ情報 | マルシェに出店するので、ぜひ来てね！ |

### 子どものナレーション（後入れ用スクリプト）

```
【オープニング】
「こんにちは！私が作ったモールドールを紹介します！」

「マルシェに出店するので、ぜひ来てください！
```

## マルシェ情報の変更

`src/compositions/MoleDollVideo.tsx` の `Scene4Closing` の配列を編集：

```tsx
{ icon: "📅", label: "日時", value: "2024年○月○日（○）" },  // ← 日付を変更
{ icon: "📍", label: "場所", value: "○○マルシェ会場" },      // ← 場所を変更
{ icon: "🕐", label: "時間", value: "10:00〜16:00" },        // ← 時間を変更
{ icon: "💰", label: "価格", value: "¥500〜" },              // ← 価格を変更
```

## プレビュー・書き出し

```bash
# Remotion Studioを起動（ブラウザで確認）
npm run start

# MP4として書き出し
npm run render
```

書き出した動画は `out/mole-doll-video.mp4` に保存されます。
