# 持ち物アプリ　公開とログインの手順

この手順書は、パソコンで上から順に進めれば、スマホで使えるところまでたどり着けるように書いています。
（手順は 2026年11月時点の Cloudflare 公式ドキュメントを確認して書いています。画面のボタン名が少し変わっていることがあります。）

全体の流れ：

1. Cloudflare のアカウントを作る
2. パソコンの準備
3. データベースを作って、アプリを公開する
4. 自分のメールアドレスだけでログインできるようにする（Access）
5. アプリに「ログインの確認に使う値」を登録する
6. スマホのホーム画面に追加する

おまけ：間違えて消したときの戻し方 / 無料プランの上限

---

## 1. Cloudflare のアカウントを作る

1. https://dash.cloudflare.com/sign-up を開き、メールアドレスとパスワードで登録します。
2. 届いたメールのリンクを押して、メールアドレスを確認します。
3. 安全のため、2段階認証（ログインのときにスマホのコードも使う設定）をオンにしておくのがおすすめです。
   右上の人のマーク →「プロフィール」→「認証」から設定できます。

## 2. パソコンの準備

1. https://nodejs.org/ から **Node.js（LTS と書かれた方）** をインストールします。
2. このアプリのフォルダ（`mochimono`）をパソコンに置きます。
3. 「ターミナル」（Mac）または「PowerShell」（Windows）を開き、フォルダに移動します。

   ```bash
   cd mochimono のフォルダの場所
   ```

4. 必要な部品を入れます（数分かかります）。

   ```bash
   npm install
   ```

5. Cloudflare にログインします。ブラウザが開くので「Allow（許可）」を押します。

   ```bash
   npx wrangler login
   ```

## 3. データベースを作って、アプリを公開する

1. データベースを作ります。

   ```bash
   npx wrangler d1 create mochimono-db
   ```

   画面に `"database_id": "xxxxxxxx-xxxx-..."` という行が出ます。

2. フォルダの中の `wrangler.jsonc` をメモ帳などで開き、
   `"database_id": "00000000-0000-0000-0000-000000000000"` の部分を、いま出てきた ID に書きかえて保存します。

3. テーブルと初期データを入れます。確認を聞かれたら `y` を押します。

   ```bash
   npm run db:migrate:remote
   ```

4. アプリを公開します。

   ```bash
   npm run deploy
   ```

   最後に `https://mochimono.○○○.workers.dev` という URL が出ます。これがアプリの住所です。メモしておいてください。

> この時点では、まだログインの設定をしていないので、URL を開いてもデータは読み込めません（「ログインが必要です」になります）。それで正しい状態です。次へ進んでください。

## 4. 自分のメールアドレスだけでログインできるようにする（Access）

メールアドレスを入れると、そこに届く6けたのコード（One-time PIN）でログインする方式にします。

### 4-1. Zero Trust を始める（初回だけ）

1. https://dash.cloudflare.com/ を開き、左のメニューから **Zero Trust** を選びます。
2. 「チーム名（team name）」を決めます。英数字で、自分だけの名前にします（例：`yamada-home`）。
   これが **チームドメイン** `yamada-home.cloudflareaccess.com` になります。あとで使うのでメモしてください。
3. プランは **Zero Trust Free（無料）** を選びます。
   支払い情報の入力を求められますが、無料プランなので請求はされません。

> チーム名は、あとから **Zero Trust → Settings（設定）** で確認できます。

### 4-2. 「メールに届くコードでログイン」をオンにする

1. **Zero Trust → Integrations（連携）→ Identity providers（ID プロバイダー）** を開きます。
2. **Add new identity provider（新しく追加）** を押します。
3. **One-time PIN** を選んで保存します。

### 4-3. アプリを守る設定をする

1. 左のメニューを Cloudflare のトップに戻し、**Workers & Pages** を開きます。
2. 一覧から **mochimono** を選びます。
3. **Access** のタブを開き、**Protect this Worker behind Access（このWorkerをAccessで守る）** を押します。
4. **All traffic（すべて）** を選びます。
5. 「Authentication policy（だれがログインできるか）」は、いったん **Cloudflare account（このアカウントのメンバー）** を選びます。
6. **Apply Access（適用）** を押します。

### 4-4. 自分のメールアドレスだけにしぼる

ここで、ログインできる人を「自分のメールアドレス1つだけ」に変えます。

1. **Zero Trust → Access controls（アクセス制御）→ Applications（アプリケーション）** を開きます。
2. いま作られた mochimono のアプリの **Edit（編集）** を押します。
3. **Policies（ポリシー）** で、許可（Allow）のルールを次のようにします。
   - Include（含める）：**Emails（メールアドレス）**
   - 値：**自分のメールアドレス**（1つだけ）
   - ほかの Include（Cloudflare account など）は消しておきます。
4. **Login methods（ログイン方法）** で **One-time PIN** にチェックを入れます。
5. **Session Duration（ログインが続く長さ）** は、スマホで毎回コードを入れずにすむよう **1 month（1か月）** などにしておくと楽です。
6. 保存します。
7. 同じ画面の **Additional settings（追加の設定）** にある **Application Audience (AUD) Tag** をコピーしてメモします（長い英数字です）。

> ⚠️ 「Email domain（メールのドメイン）」に `gmail.com` などを入れると、**Gmail を使っている人全員**がログインできてしまいます。必ず「Emails」で自分のアドレスを1つだけ入れてください。

## 5. アプリに「ログインの確認に使う値」を登録する

アプリの中でも、毎回「本当に Access でログインした本人か」を確かめています。そのための値を登録します。
コマンドを打つと値を聞かれるので、貼りつけて Enter を押します（画面には表示されません）。

```bash
npx wrangler secret put ACCESS_TEAM_DOMAIN
# → 4-1 のチームドメイン（例：yamada-home.cloudflareaccess.com）

npx wrangler secret put ACCESS_AUD
# → 4-4 でコピーした AUD タグ

npx wrangler secret put ALLOWED_EMAIL
# → 自分のメールアドレス（念のための二重チェック）
```

これで完成です。メモした `https://mochimono.○○○.workers.dev` を開くと、

1. メールアドレスを入れる画面が出る
2. 自分のアドレスを入れると、メールに6けたのコードが届く
3. コードを入れるとアプリが開く

という流れになります。はじめて開いたときは「はじめの案内」が出るので、家族の名前 → 子どもの身長など → お米の量 → 置き場所の確認、の順に進めてください。

> 自分以外のアドレスを入れても、コードは届かずログインできません。

## 6. スマホのホーム画面に追加する

アプリのようにアイコンから開けるようになります。先に一度ブラウザでログインしておいてください。

**iPhone（Safari）**

1. Safari でアプリの URL を開きます。
2. 画面下の **共有ボタン**（四角から矢印が出ているマーク）を押します。
3. **「ホーム画面に追加」** を選び、右上の **「追加」** を押します。

**Android（Chrome）**

1. Chrome でアプリの URL を開きます。
2. 右上の **︙（メニュー）** を押します。
3. **「ホーム画面に追加」**（または「アプリをインストール」）を選びます。

ログインが切れたときは、もう一度メールのコードを入れればOKです。

## 間違えて消したときに戻す方法（Time Travel）

アプリの中で消したものは、5秒間「元に戻す」が出ます。それを過ぎてしまったときは、データベースごと「その時刻の状態」に戻せます。

- 無料プランでは **7日前まで** 戻せます。
- 戻すと、**その時刻より後に入れた変更はすべて消えます**。いつに戻すかをよく確かめてください。
- 念のため、先に「設定 → バックアップ」で今のデータを保存しておくと安心です。

手順（パソコンで、mochimono のフォルダで行います）：

1. 戻したい時刻を決めます。日本時間なら最後に `+09:00` を付けます。
   例：2026年11月6日の午後3時の状態に戻すなら `2026-11-06T15:00:00+09:00`

2. その時刻に戻せるか確かめます。

   ```bash
   npx wrangler d1 time-travel info mochimono-db --timestamp="2026-11-06T15:00:00+09:00"
   ```

3. 戻します。確認を聞かれたら `y` を押します。

   ```bash
   npx wrangler d1 time-travel restore mochimono-db --timestamp="2026-11-06T15:00:00+09:00"
   ```

4. 終わると「元に戻すならこのしおり（bookmark）へ」という値が表示されます。
   戻しすぎたときは、その値を使って

   ```bash
   npx wrangler d1 time-travel restore mochimono-db --bookmark=表示された値
   ```

   で、戻す前の状態に戻せます。

## 無料プランの上限と、今の使い方なら十分足りること

| 項目 | 無料プランの上限 | このアプリの使い方 |
|---|---|---|
| アプリへのアクセス（Workers） | 1日 10万回 | 1日に何十回〜数百回なので、まったく問題なし |
| データベースの読み込み（D1） | 1日 500万行 | 1回の表示で数百行。1日に何千回開いても足りる |
| データベースへの書き込み（D1） | 1日 10万行 | −／＋やまとめ保存で1日 数十〜数百行 |
| データベースの大きさ | 1つ 500MB（アカウント全体で 5GB） | 家族5人分の持ち物なら 1MB にも届きません |
| 巻き戻し（Time Travel） | 7日前まで | — |
| ログイン（Zero Trust Free） | 50人まで | 使うのは1人だけ |

上限はどれも「1日ごと」で、日本時間の朝9時（世界時の0時）に元に戻ります。
もし上限をこえても、お金がかかることはなく、その日だけ保存ができなくなるだけです。

## 困ったとき

- **「ログインが必要です」と出る**：ページを読み込みなおして、メールのコードでログインしなおしてください。5章の3つの値（特に AUD タグ）が正しいかも確かめてください。
- **「つながりにくくなっています」と出る**：電波のよいところで、少し待ってからためしてください。
- **アプリを新しくしたいとき**（作り直したファイルをもらったとき）：フォルダを置きかえてから `npm install` → `npm run db:migrate:remote` → `npm run deploy` の順に打てばOKです。データはそのまま残ります。
